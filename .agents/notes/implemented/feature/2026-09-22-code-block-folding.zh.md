# Agent Note: 代码块折叠

Status: implemented

[English](2026-09-22-code-block-folding.md) | 中文

## 问题

即使读者只想阅读周围正文，长代码块仍占据阅读空间。共享渲染器也用于文档预览和 Mermaid 源码视图，因此隐藏源码必须兼容这些视图的布局覆盖，同时不破坏复制功能或内容 ref。

## 决策

`CodeBlock` 拥有默认展开的横幅按钮，必须传入本地化的收起／展开 label。折叠是组件内的查看状态，不是会话事件或设置。内容包装节点保持挂载并携带 `hidden`；其局部 `display: none !important` 规则覆盖消费方的滚动区 display 规则。复制仍可用，读取传入的完整源码。

此功能扩展共享渲染器，不改变[文档预览的滚动区所有权](2026-09-09-sidebar-and-preview-interaction-polish.zh.md)或 [Mermaid 源码开关](2026-09-17-assistant-markdown-mermaid-diagrams.zh.md)。

## 考虑过的替代方案

**卸载折叠的源码。** 卸载会丢弃高亮 DOM，并断开持有方的内容 ref。保留包装节点可让这些节点在流式增长与定稿期间保持身份不变。

**依赖浏览器的 hidden 样式或普通选择器优先级。** 作者的 display 规则会覆盖浏览器默认样式，消费方的滚动区选择器也可能覆盖普通组件规则。important 声明仅作用于本组件的隐藏内容。

## 后果

折叠节省可见空间，而非 DOM 内存或高亮工作量。无横幅的代码块没有折叠控件。组件测试覆盖源码复制和流式期间的折叠状态保留；录制会话浏览器用例覆盖本地化键盘控件、侧边栏样式下的实际可见性，以及折叠时复制。DOM fixture（测试前置数据）包含流式 math 代码围栏，因为定稿前它们仍渲染为源码。
